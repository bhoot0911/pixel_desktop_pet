# 🐾 Pixel Desktop Pet

> A lightweight pixel-art desktop companion designed to bring interactive virtual pets to your screen.

**Pixel Desktop Pet** is a personal project featuring two virtual companions — **Cosmos 🐱**, a playful cat, and **Burrito 🐼**, a friendly panda. The project combines pixel art, animation, and interactive web technologies to create a simple and engaging desktop-pet experience.

---

## ✨ Overview

The idea behind Pixel Desktop Pet is simple: create a small virtual companion that can live alongside you while you work, study, or browse.

Rather than being a complex application, the project focuses on the little interactions that make a digital character feel more alive — movement, animations, reactions, and personality.

## 🐾 Meet the Pets

### Cosmos 🐱

Cosmos is the cat companion of the project. Designed with playful animations and interactive behavior, Cosmos adds a curious and energetic presence to the desktop.

### Burrito 🐼

Burrito is the panda companion. With a calmer personality and a cute pixel-art design, Burrito brings a more relaxed presence to the experience.
